Étape Initiale • Classroom & Google Agenda

Module 1 : Configuration & Communication

Objectif : Ouvrir votre premier cours virtuel, inviter vos élèves sénégalais et sécuriser la communication.

⏳
Durée estimée
25 à 30 minutes
➔ ➔ ➔ ➔
1

Se connecter sans erreur de compte

Pour éviter les conflits lorsque vous avez plusieurs profils ouverts dans votre navigateur, utilisez impérativement l'URL directe qui force le compte actif n°0 :

classroom.google.com/u/0/
⚠️ Règle d'or Sénégal : Vous devez vous connecter avec votre adresse personnelle terminant strictement par @gmail.com.
2

Créer votre premier cours

Sur la page principale de Classroom :

  1. Repérez et cliquez sur le gros bouton + (en haut à droite de l'écran).
  2. Dans le menu déroulant, sélectionnez "Créer un cours".
  3. Indiquez le nom du cours (ex. : Électricité Générale - CFP Thiès).
  4. Validez en cliquant sur le bouton bleu Créer.
3

Inviter les élèves & collègues

Cliquez sur l'onglet Personnes. Vous avez deux méthodes d'invitation :

🔑 MÉTHODE 1 : Code

Idéal en classe. Affichez le code, les élèves l'entrent sur leur smartphone.

✉️ MÉTHODE 2 : E-mail

Cliquez sur le + et tapez l'adresse `@gmail.com` de l'élève.

4

Gérer le Flux

Le Flux est le tableau d'affichage. Sécurisez-le :

  • Cliquez sur la roue crantée (Paramètres).
  • Section Général ➔ Flux.
  • Sélectionnez : "Les élèves peuvent uniquement commenter".
5

L'Agenda de la classe

Google synchronise automatiquement un calendrier d'équipe. Dès que vous fixez une date limite, elle est inscrite dans l'agenda des élèves.

🎯

Défi de Réalité Professionnelle n°1

Simulez la rentrée : créez un cours, verrouillez le Flux, et partagez votre code avec 2 collègues formateurs pour qu'ils rejoignent votre classe !

Étape 2 • Google Drive & Docs

Module 2 : Création de Leçons & Devoirs

Objectif : Structurer vos chapitres et utiliser la fonction "Faire une copie par élève".

➔ ➔ ➔ ➔
1

Découvrir "Travaux et devoirs"

C'est ici que se trouve le véritable atelier pédagogique. Cliquez sur l'onglet Travaux et devoirs en haut.

2

Créer des "Thèmes"

Les Thèmes agissent comme des intercalaires de classeur.

  1. Cliquez sur + Créer puis sur Thème.
  2. Donnez un titre clair et cliquez sur Ajouter.
3

Partager de la "Documentation"

La Documentation sert à transmettre des PDF ou vidéos sans attendre de travail en retour. Cliquez sur + Créer ➔ Documentation.

4

Créer un "Devoir" noté

Cliquez sur + Créer ➔ Devoir. Indiquez le titre, la consigne, le barème et la date limite.

5

Option : "Faire une copie par élève"

✨ "Faire une copie par élève"

Classroom va générer un fichier nommé au prénom et nom de chaque élève pour qu'ils travaillent individuellement.

🎯

Défi de Réalité Professionnelle n°2

Créez un Thème. Ajoutez-y un Devoir contenant un fichier Google Docs. Cochez Faire une copie par élève et publiez le devoir !

Étape 3 • Google Forms & Sheets

Module 3 : Évaluation Automatique

Objectif : Créer un Quiz auto-corrigé et importer les notes en un clic.

➔ ➔ ➔
1

Créer un "Devoir avec questionnaire"

Dans Travaux et devoirs, cliquez sur + Créer. Choisissez Devoir avec questionnaire pour générer un formulaire auto-corrigé.

2

Les 4 Règles d'Or (@gmail.com)

1. Collecter les e-mails dans Forms.
2. Limiter à 1 réponse.
3. Un seul fichier (le form) attaché.
4. Importation activée dans Classroom.
3

Importer les notes et "Rendre"

Ouvrez le devoir et cliquez sur "Importer les notes". Les scores sont en "Brouillon". Cochez les élèves puis cliquez sur Rendre.

4

Analyser sur Sheets

Dans Forms, onglet Réponses, cliquez sur l'icône verte "Lien vers Sheets" pour avoir un tableau détaillé.

🎯

Défi de Réalité Professionnelle n°3

Créez un mini-quiz, demandez à des collègues d'y répondre, puis cliquez sur Importer les notes et Rendre.
