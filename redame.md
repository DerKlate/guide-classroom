# 🇸🇳 Académie Virtuelle des Formateurs - Sénégal

Guide interactif pas-à-pas pour la prise en main de **Google Classroom, Drive, Docs, Forms et Sheets** à destination des formateurs et enseignants des CFP du Sénégal.

## 🚀 Caractéristiques
- **Wizard 3 Modules :** Configuration & Flux, Cours & Devoirs partagés, Quiz auto-corrigés & Sheets.
- **Vidéo Assist :** Vidéos YouTube en français calées à la seconde exacte de chaque manipulation.
- **Suivi hors-ligne :** Progression sauvegardée localement dans le navigateur.
- **Adapté Mobile & Économie de Données :** Optimisé pour smartphones (BYOD).

## 📁 Structure du projet
- `index.html` : Structure HTML principale (Tailwind CSS via CDN).
- `css/style.css` : Design personnalisé (patterns africains, animations).
- `js/app.js` : Logique de l'application (wizard, player vidéo, persistance).

## 🛠️ Technologies
- HTML5 / CSS3
- Tailwind CSS
- Vanilla JavaScript
